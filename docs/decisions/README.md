# Architecture & Product Decision Records

Simpan ADR untuk keputusan lintas domain yang sulit dibalik: arsitektur, storage, tenancy, integrasi SSO/PSrE, data residency, risk ownership dan compatibility. ADR merekam **trade-off**, bukan sekadar pilihan final.

Gunakan [template ADR](ADR-template.md). Nama dokumen baru: `adr-0001-topik-singkat.md` (nomor unik berurutan). Status: PROPOSED → ACCEPTED → SUPERSEDED / REJECTED. `ACCEPTED` memerlukan approver sesuai penugasan organisasi; keputusan belum resmi jangan ditandai accepted.

ADR v2 yang saat ini tercatat masih sebagai *draft* di [Technical Specification](../architecture/specifications/Spesifikasi-Teknis-QA-Manager-v2.md); pecah menjadi ADR individual ketika keputusan telah dievaluasi.
