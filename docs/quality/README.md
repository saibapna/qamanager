# Quality — QA, QC dan Acceptance

Domain ini menyimpan metode, standar, test evidence, prosedur QA, test plan QC, UAT/ULO, quality gate, dan *report conformance*. Pisahkan **quality proses (QA)** dari **quality produk (QC)** serta keputusan penerimaan organisasi.

- **PDF ULO/UAT legacy:** [Spesifikasi template 1:1](pdf/Spesifikasi-Teknis-Template-PDF-v1.md), historis; penerimaan formal tetap membutuhkan fixture resmi.
- **Fixture dan uji visual:** [Panduan fixture](../../fixtures/README.md) — source-of-truth test fixture tetap di `fixtures/`.
- **Alur QA/QC target:** [PRD QA Manager v2](../product/prd/PRD-QA-Manager-v2.md), [Technical Specification](../architecture/specifications/Spesifikasi-Teknis-QA-Manager-v2.md).

**Penempatan dokumen baru:** `qa/` untuk QA Plans/checklist dan CAPA, `qc/` untuk strategi/test suites, `uat/` untuk penerimaan, `pdf/` untuk template/form, `reports/` untuk metrik dan laporan. Jangan unggah evidence/data pribadi ke repo publik.
