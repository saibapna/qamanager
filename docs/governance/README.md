# Governance & Government Compliance

Domain ini mengelola struktur kewenangan, proses persetujuan, RACI, policy, kontrol SPBE, matriks regulasi dan dokumen keputusan administratif. **Dokumentasi bukan penerbit kewenangan formal.**

- Kerangka awal mandat, acceptance, SPBE dan pelindungan data: [PRD v2](../product/prd/PRD-QA-Manager-v2.md).
- Pemisahan role teknis, risk acceptance dan signoff: [Technical Specification v2](../architecture/specifications/Spesifikasi-Teknis-QA-Manager-v2.md).

**Penempatan dokumen baru:** `raci/`, `policies/`, `compliance/`, `approvals/` jika ada isinya. Selalu rekam sumber regulasi, versi, pasal, instansi pemilik, tanggal pemeriksaan dan status persetujuan.
